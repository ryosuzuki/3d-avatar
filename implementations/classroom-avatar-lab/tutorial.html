1. Open the starter

Unzip the project. In Unity Hub choose Add → Add project from disk and select the project folder. Open with Unity 6000.4.5f1. Wait for package import and compilation.

2. Supply YOUR avatar

Download Gaussian · PLY from your private result. Copy it to the starter project’s Assets folder as avatar.ply. No student avatar is included in the starter.

3. Import and build

Unity menu: Classroom → Avatar Tutorial. Click Import, then Build the Gaussian demo scene, then Open Game view. Press Unity’s Play triangle.

What this does — and does not do

This is a static, orbitable Gaussian avatar. It does not create a skeleton or import the neural dance as a Unity animation. It preserves the exported attributes without extra compression; it cannot recover details that were lost during generation or color baking.

The starter was tested on desktop Unity / Metal. Quest, iOS, Android and stereo AR compatibility are not verified. Do not equate this desktop lesson with an AR-device deployment.

Want to try the experimental reconstructed mesh?

Use the separate Mixamo · textured OBJ ZIP on your result page, not “Download everything”. Upload that ZIP in Mixamo → orient the model → Next → place the markers → Next → review the rig → Next → select an animation. Download FBX for Unity, with skin, at 30 fps. This remains an experimental approximate mesh; automatic rigging does not repair its shape.

In Unity drag the downloaded FBX into Assets. Select it → Inspector → Rig → Animation Type: Humanoid → Avatar Definition: Create From This Model → Apply. In the Animation tab enable Loop Time for a loop. Drag the model into the Scene, create an Animator Controller in Assets, drag the animation into its Animator graph, and assign that controller to the model’s Animator component. Press Play. These Mixamo steps are instructions, not an independently verified upload of your face to Adobe.

For the exact highest-fidelity server appearance, download Neural dance · MP4. A Unity VideoPlayer can play it, but that is a flat video surface, not a 3D animated character.
