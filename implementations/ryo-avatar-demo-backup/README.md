Snapshot of six avatar interaction and explainer projects on 2026-10-08. Includes runtime assets, source, manifests, and replay instructions in each project README. Originals remain in Storage and are unchanged.

The Transformer interactive project is an in-progress checkpoint, not a claim of completed interactive testing or deployment. Other projects contain previously delivered demos. No API credentials are included; live API use requires separately configured credentials.

`snapshot-manifest.json` records original locations and SHA-256 hashes. Install dependencies and launch using each project README. Existing nested .gitignore files may exclude assets, but initial backup explicitly includes them.
