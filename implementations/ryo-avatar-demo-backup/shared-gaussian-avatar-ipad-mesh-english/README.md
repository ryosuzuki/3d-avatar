# Ryo in today's iPad 3D Scanner App textured mesh

English narrated 56.27-second saved Jev-plan replay using the exact supplied 160,000-Gaussian Ryo avatar. Room source captured on 2026-10-08, not the earlier Quest room.

Run `node server.mjs`, then open its printed localhost URL. Play / pause, timeline and orbit camera are available. Python `python3 -m http.server 8000` also supports normal replay when served from this directory.

Room and avatar positions are manually placed prototype coordinates, not measured physical AR registration. The two room versions use separate scan coordinate systems and different room viewpoints; do not treat them as co-registered quality measurements.

Limitations: approximate rig and shoulder deformation; stock synthetic English voice; no lip sync, live Q&A or live AI. Existing Jev selections and verified narration reused without any new API request. Scan holes and incomplete regions are source limitations.
