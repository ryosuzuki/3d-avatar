# A sketch comes to life

Derived from transformer-avatar-sketch, retaining the exact original Ryo Gaussian avatar and 2026-10-08 iPad Scaniverse room. The avatar draws a pendulum, the same lines acquire depth, and it swings beside a hand-drawn wave.

Run `npm install` then `AVATAR_EXPLAINER_PORT=8796 npm start`; open http://127.0.0.1:8796.

38-second authored animation, not live sketch recognition or calibrated AR. Approximate avatar rig/open palm, no finger articulation or lip sync. Wave is explanatory, not a streamed sensor measurement. English OpenAI shimmer voice. Original assets unchanged.
