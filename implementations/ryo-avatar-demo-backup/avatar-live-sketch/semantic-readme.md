# Live semantic sketch correction

OpenAI generates the explanation and semantic composition/parameters, rather than choosing a prerecorded answer or supplying arbitrary mesh vertices. A bounded deterministic compiler turns the composition into smooth spatial ink.

Supported validated scientific geometry: bent H2O (104.5 degrees, two O-H bonds), linear CO2 (180 degrees, two C=O double bonds), three-component teaching attention (dot products, division by sqrt(3), stable softmax). Molecule comparisons own the board, preventing unrelated concept diagrams from covering atoms. Unsupported molecular topology is not inferred; a concept diagram is permitted and explicitly illustrative. Numeric attention coordinates are a low-dimensional teaching example, not a projection of a trained model.

The same original Ryo Gaussian avatar and iPad room remain. Ink unfolds from flattened outlines into depth; original prerecorded media remain unchanged. Answers/audio are generated for actual questions. Finger grip, skin deformation, AR occlusion and physical iPad/Safari performance remain unverified/approximate.

Private access: http://127.0.0.1:8813/ through existing encrypted Tailscale TCP forwarding. The service binds only 127.0.0.1:8811. No public tunnel. The browser uses HTTP on the private tailnet, not HTTPS; text input only. Existing provider credential stays backend-only. Cookies protect generated audio; histories are process-memory only.

Tests: python3 test-semantic.py; managed-browser/FIFO verify-semantic.mjs for three new/context questions; verify-semantic-and-record.mjs for actual generated answer audio capture and four viewport layouts.
